# Song-list-to-mp3-converter


**HOW IT WORKS:**

Simply put in a list of songs (search queries) in the songs.txt file separated by new lines (you can delete the sample songs in the songs.txt file). All this code does is takes each query from the list and searches it and converts and downloads it as an mp3 file.


**TO RUN:**

1. In the folder in your file explorer right click anywhere and click on "Open in Terminal".
2. Then type `python .\mp3converter.py` and press enter.
